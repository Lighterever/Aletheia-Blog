# ℵ · aletheia

> 个人博客。think, write, unfold.

纯前端极简博客，SPA + History API 路由。主页展示思想片段和入口，密钥室作为内容门槛，解锁后进入文章检索页浏览和阅读。支持 GitHub Flavored Markdown、KaTeX 数学公式、语法高亮、深浅双主题。

---

## 项目结构

```
/
├── index.html         ← 全部视图层
├── style.css          ← CSS 变量驱动的双主题样式
├── app.js             ← OOP 核心（9 类 + MarkdownRenderer）
├── data.js            ← 文章数据（由构建脚本自动生成）
├── timeline-data.js   ← 时间轴数据（由构建脚本自动生成）
├── vercel.json        ← SPA rewrite 规则
├── articles/          ← 文章源文件（.md + YAML frontmatter）
├── timeline/          ← 学习轨迹源文件（.md + YAML frontmatter）
├── scripts/           ← 构建工具
└── README.md
```

## 页面与路由

SPA 架构，History API 路由（无 `#`）。

| URL | 页面 | 导航栏 | 需要解锁 |
|-----|------|--------|----------|
| `/` | 主页 | 显示 | 否 |
| `/vault` | 密钥输入页 | 显示 | 否 |
| `/timeline` | 学习轨迹时间轴 | 隐藏（终端式顶栏） | 否 |
| `/articles` | 文章检索页 | 显示 | 是 |
| `/article/{id}` | 文章阅读页 | 隐藏 | 是 |
| `/readme` | README 文 | 隐藏 | 否 |

### 主页（`/`）

Hero 区展示 `ℵ · aletheia` 标题和标签行，密钥室入口按钮，README 卡片，footer。Caesar 密码轮背景动画（hover 脉冲发光）。

### 密钥室（`/vault`）

终端风格输入框，密钥 `aletheia` 解锁。Matrix Rain 背景动画 + 环形扩散解锁特效 + 解密进度动画。

- `sessionStorage` 持久化解锁状态，刷新不丢失，关闭标签页清除
- 未解锁访问 `/articles` 或 `/article/*` 自动重定向到 `/vault`

### 文章检索页（`/articles`）

四层布局：
1. **顶栏**：ℵ Logo + 搜索框（`grep...`）+ Exit 按钮
2. **终端风格列表头**：`DATE` / `TITLE` / `TAGS` 列头，可点击排序
3. **标签筛选栏**：多选标签按钮 + OR/AND 切换 + 筛选计数 + 清除
4. **文章列表**：日期 ── 标题  #标签

搜索匹配标题、标签和正文，300ms 防抖。标签支持多选组合和 OR/AND 逻辑。

### 文章阅读页（`/article/{id}`）

打字机标题动画、Markdown 渲染（marked.js + github-markdown-css）、highlight.js 语法高亮、KaTeX 数学公式、代码块语言标签 + 复制按钮、标题锚点、右侧 TOC 目录面板、阅读进度条。液态玻璃毛效果阅读器。

### 学习轨迹时间轴（`/timeline`）

可平移、可缩放的横向画布时间轴。进入时导航栏自动收起，顶部为终端风格控制栏（左侧红黄绿圆点、`← 返回` 按钮、年份/月份/日期三级下拉筛选、查看跳转、缩放滑块、展开/折叠全部、主题切换 `◐`）。

**交互方式**：
- **右键拖拽 / 触控板双指滑动**：平移画布
- **⌘+滚轮 / Ctrl+滚轮 / 双指捏合**：以鼠标/双指为中心缩放（时间轴越放大节点间距越宽，同时年/月/日标签自动切换）
- **鼠标悬浮节点**：快速预览卡片（移走即折叠）
- **左键点击节点**：锁定展开卡片（再点折叠），关闭有收缩动画
- **方向键**：平移画布，`+`/`-` 缩放，`0` 重置
- **定位按钮**（右下角）：跳转到今天或最近记录
- **主题切换**（控制栏右侧 `◐`）：深浅色切换，状态持久化

**布局**：单条时间轴从左到右延伸（左边界固定在 2026 年 1 月 1 日）。上方彩色圆条表示各学习主题的持续时段（不同主题不同颜色），圆条 title 支持冻结表头效果——右移超出视口左边界时文字自动跟随保持可见，左移滚回时恢复正常位置。所有学习记录节点统一排布在同一条时间线上；同一天若有多条记录（来自不同主题），节点合并展示（实心为单记录，空心圆环为合并记录）。卡片向下展开，内容按来源主题分段，各段前标注主题名。

**拖动边界**：平移范围受动态边界限制，左右保留 200px 边距；展开卡片后画布高度自动增加，可向下滚动查看，关闭卡片后高度收缩。

**缩放与信息密度**（`pixelsPerDay = 50 × scale^1.3`，平滑连续变化，无阶梯感）：

| 缩放 | px/天 | 显示 |
|------|-------|------|
| 25%-30% | 9-15px | 概览：主题条 + 时间线下方年份标记（`2026`），节点日期隐藏 |
| 31%-60% | 16-32px | 迷你：主题条 + 时间线下方月份标记（`2026/5`），节点日期隐藏 |
| 61%-120% | 33-65px | 卡片：完整日期节点 `2026-05-16` + 可展开卡片 |
| >120% | 66-125px | 放大：大号节点 + 320px 宽卡片 |

**顶端控制栏组件**：
- 红黄绿终端圆点（左上角固定）
- `← 返回` 按钮
- 日期标签 `📅 2026年5月16日 星期六`
- 年份 / 月份 / 日期 下拉筛选 + 跳转
- 缩放滑块 25%-200%
- 展开全部 / 折叠全部
- 主题切换 `◐`（暗）/ `◑`（浅）

## OOP 架构

```
App（主控制器）
├── Theme              ← 深浅色主题切换（localStorage 持久化）
├── Navbar             ← 全局导航栏（毛玻璃 + 滚动态）
├── Typewriter         ← 打字机标题动画
├── MatrixRain         ← Matrix数字雨背景（密钥室专属）
├── ArticleReader      ← 文章阅读（MarkdownRenderer + TOC + 进度条）
├── TimelineCanvas     ← 时间轴画布（平移/缩放/节点/检索/定位）
├── MarkdownRenderer   ← Markdown 渲染增强（静态类：语法高亮/复制/锚点/表格）
├── Vault              ← 密钥验证 + 解锁特效（Web Animation API）
└── Crypto             ← AES 解密（静态方法）
```

统一导航入口 `App.navigate(page)`，每次切换先隐藏所有页面。

## 添加文章

在 `articles/` 目录下创建 `.md` 文件，使用 YAML frontmatter：

```markdown
---
title: 文章标题
date: 2026-05-15
tags: [数学, 算法]
id: article-slug
---

# 标题

正文 Markdown...
```

运行构建脚本生成 `data.js`：

```bash
node scripts/build.js
```

- `id` 可选，不填使用文件名
- 标签用逗号分隔，支持中文：`tags: [人际, 心理]`
- 数学公式用 KaTeX 语法：行内 `$E=mc^2$`，行间 `$$\int$$`

## 添加学习记录

在 `timeline/` 目录下创建 `.md` 文件，每个文件对应一个学习主题，使用 YAML frontmatter + `### 日期` 格式：

```markdown
---
id: cryptography
title: 密码学入门
tags: [密码学, 安全]
start: 2026-04-29
end: 2026-05-15
---

### 2026-04-29
读了 Katz/Lindell 第一章，了解密码学的基本定义。

💡 密码学的严谨精巧让我有共鸣——不是黑箱魔法，是可证明的安全性。

### 2026-05-01
tags: CTF, Cryptohack
探索 CTF 平台：picoCTF、Cryptohack、CryptoPals。
```

**Front Matter 字段**：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 否 | 主题标识，不填使用文件名 |
| `title` | 否 | 主题名称，显示在时间轴上方彩色条。**不填则此文件为零散记录（无主题条），节点直接排在时间线上** |
| `tags` | 否 | 主题级标签列表，所有该主题的节点卡片均显示 |
| `start` | 否 | 开始日期 `YYYY-MM-DD`，不填自动取第一条记录日期 |
| `end` | 否 | 结束日期，不填视为进行中 |

**内容格式**：
- 以 `### YYYY-MM-DD` 标记每一天的学习记录
- 正文可以是多段文字，支持 Markdown
- 以 `💡` 开头的行标记为"灵感时刻"，节点会有脉冲高亮效果
- **条目级标签**：在某条记录正文中写入 `tags: 标签1, 标签2`（大小写不敏感，支持 `,` `，` `、` 分隔），该节点卡片独立显示这些标签（与主题级标签合并去重）
- 同一天不同主题的多条记录会**自动合并为一个节点**，卡片按主题分段展示

**零散记录**（不需要主题）：
如果只想随手记录不需要归类主题，可以创建一个 `.md` 文件不写 `title` 字段（或整个 frontmatter 都不写），该文件的记录将以独立节点出现在时间轴上（无彩色主题条）。

运行构建脚本同时生成 `data.js` + `timeline-data.js`：

```bash
node scripts/build.js
```

如 `timeline/` 目录不存在，构建脚本会跳过时间轴生成，不影响原有文章构建。
