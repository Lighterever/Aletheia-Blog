# 个人博客「学习轨迹」功能规范文档

> 本文档定义博客网站「学习轨迹」功能的技术实现方案，供用户自行改造使用。

---

## 1. 项目概述

### 1.1 功能说明

「学习轨迹」是一个可缩放的时间轴页面，以类似地图缩放的交互方式展示用户的学习历程。用户可以：
- 拉远视角：查看学习主题全景（每个主题一行）
- 中距视角：按自然周分组查看学习进度
- 拉近视角：精确到每一天的详细记录

### 1.2 设计理念

- **渐进式信息密度**：用户控制信息展示的粒度，而非一次性倾倒
- **地图式缩放隐喻**：缩放是浏览而非导航，降低认知负担
- **灵感时刻突出**：💡 标记的灵感瞬间在整个时间轴中具有视觉优先级
- **与现有风格一致**：保持博客的暗色极简密码学美学

### 1.3 文件变更清单

| 文件 | 操作 |
|------|------|
| `index.html` | 修改：新增「轨迹」导航入口和时间轴页面容器 |

### 2.2 学习主题文件格式

每个学习主题对应一个 `.md` 文件，放在 `timeline/` 目录。

#### Front Matter 字段

```markdown
---
id: lattice-crypto          # 唯一标识符（英文字母、数字、连字符）
title: 格密码学              # 显示标题
start: 2026-03-10           # 开始日期（YYYY-MM-DD）
end: 2026-04-22             # 结束日期（留空表示进行中）
tags: [密码学, 后量子]       # 标签数组
---
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一标识，用于内部引用 |
| `title` | string | 是 | 显示在时间轴上的标题 |
| `start` | string | 是 | 开始日期，格式 YYYY-MM-DD |
| `end` | string | 否 | 结束日期；留空或 `ongoing` 表示进行中 |
| `tags` | array | 否 | 标签数组，用于筛选 |

#### 正文格式

正文按日期记录，使用 `### YYYY-MM-DD` 作为日期标题：

```markdown
### 2026-03-10
开始看 Regev 的原始论文，LWE 的定义先过了第一遍

### 2026-03-12
噪声采样的部分卡住了，均匀分布和高斯分布的区别还没搞清

### 2026-03-18
💡 突然理解了！LWE 的噪声不是"错误"，是安全性的来源

### 2026-03-20
SIS 和 LWE 是双胞问题，对偶关系终于通了

### 2026-04-22
完结，开始看 Ring-LWE
```

#### 特殊标记

- `💡` 符号标记灵感时刻，会在时间轴上用特殊样式突出显示
- 无记录的日子不需要写入，时间轴会自动用细线表示空白
- 同一日期多条记录直接连续书写

#### 3.1.2 新增函数

在 `parseMdFile` 函数后添加：

```javascript
// ========== 时间轴数据解析 ==========

/**
 * 解析时间轴主题文件
 * @param {string} filePath - 文件路径
 * @returns {Object} 解析后的主题对象
 */
function parseTimelineFile(filePath) {
    const raw = fs.readFileSync(filePath, 'utf-8');
    const trimmed = raw.trim();

    if (!trimmed.startsWith('---')) {
        throw new Error(`Missing frontmatter in ${filePath}`);
    }

    const secondDelim = trimmed.indexOf('---', 3);
    if (secondDelim === -1) {
        throw new Error(`Unclosed frontmatter in ${filePath}`);
    }

    const frontmatterText = trimmed.slice(3, secondDelim).trim();
    const content = trimmed.slice(secondDelim + 3).trim();
    const meta = parseFrontmatter(frontmatterText);

    const basename = path.basename(filePath, '.md');

    // 解析每日记录
    const entries = parseTimelineContent(content);

    return {
        id: meta.id || basename,
        title: meta.title || basename,
        start: meta.start || '',
        end: meta.end || null,  // null 表示进行中
        tags: meta.tags || [],
        entries: entries,
    };
}

/**
 * 解析时间轴正文内容，提取每日记录
 * @param {string} content - 正文内容
 * @returns {Array} 每日记录数组
 */
function parseTimelineContent(content) {
    const lines = content.split('\n');
    const entries = [];
    let currentDate = null;
    let currentContent = [];
    let isInsight = false;

    for (const line of lines) {
        // 匹配日期标题 ### YYYY-MM-DD
        const dateMatch = line.match(/^###\s+(\d{4}-\d{2}-\d{2})/);
        if (dateMatch) {
            // 保存之前的记录（过滤掉只有空白内容的条目）
            if (currentDate) {
                const trimmedContent = currentContent.join('\n').trim();
                if (trimmedContent.length > 0) {
                    entries.push({
                        date: currentDate,
                        content: trimmedContent,
                        isInsight: isInsight,
                    });
                }
            }
            currentDate = dateMatch[1];
            currentContent = [];
            isInsight = false;
        } else if (currentDate) {
            // 检查灵感标记
            if (line.includes('💡')) {
                isInsight = true;
            }
            currentContent.push(line);
        }
    }

    // 保存最后一条记录（同样过滤空白）
    if (currentDate) {
        const trimmedContent = currentContent.join('\n').trim();
        if (trimmedContent.length > 0) {
            entries.push({
                date: currentDate,
                content: trimmedContent,
                isInsight: isInsight,
            });
        }
    }

    return entries;
}

/**
 * 生成 timeline-data.js 文件内容
 * @param {Array} topics - 时间轴主题数组
 * @returns {string} JS 文件内容
 */
function generateTimelineJs(topics) {
    // 按开始日期排序
    topics.sort((a, b) => new Date(a.start) - new Date(b.start));

    const entries = topics.map((t) => {
        const entriesJson = JSON.stringify(t.entries);
        const tagsStr = JSON.stringify(t.tags);
        const endValue = t.end ? `'${t.end}'` : 'null';

        return `    {
        id: '${escapeStringLiteral(t.id)}',
        title: '${escapeStringLiteral(t.title)}',
        start: '${escapeStringLiteral(t.start)}',
        end: ${endValue},
        tags: ${tagsStr},
        entries: ${entriesJson}
    }`;
    });

    return `/**
 * 时间轴数据文件（由 scripts/build-articles.js 自动生成）
 * 请勿手动编辑此文件，在 timeline/ 目录下添加 .md 文件后运行 node scripts/build-articles.js
 */

const timelineData = [
${entries.join(',\n')}
];
`;
}
```

#### 3.1.3 修改 main 函数

在 `main()` 函数中新增 timeline 数据生成调用：

```javascript
function main() {
    // ... 现有的 articles 处理逻辑不变 ...

    // ========== 时间轴数据处理 ==========
    if (fs.existsSync(TIMELINE_DIR)) {
        const timelineFiles = fs.readdirSync(TIMELINE_DIR)
            .filter((f) => f.endsWith('.md'))
            .sort();

        if (timelineFiles.length > 0) {
            const topics = timelineFiles.map((f) => {
                const filePath = path.join(TIMELINE_DIR, f);
                console.log(`  parsing timeline: ${f}`);
                return parseTimelineFile(filePath);
            });

            const timelineOutput = generateTimelineJs(topics);
            fs.writeFileSync(TIMELINE_OUTPUT, timelineOutput, 'utf-8');
            console.log(`\nGenerated timeline-data.js with ${topics.length} topic(s)`);
        } else {
            console.log('\nNo timeline .md files found in timeline/');
        }
    } else {
        console.log('\ntimeline/ directory not found, skipping timeline generation');
    }
}
```

## 5. 数据渲染 — TimelineRenderer 类

### 5.1 类结构

在 `app.js` 文件末尾（`if (document.readyState === 'loading')` 之前）添加完整的 TimelineRenderer 类。

**注意**：`app.js` 整体包裹在 `(function() { ... })()` IIFE 中，TimelineRenderer 定义在 IIFE 内部。`timelineData` 由 `timeline-data.js` 在全局作用域定义，因此在 IIFE 内部通过 `typeof timelineData !== 'undefined'` 安全访问（未加载时 fallback 为空数组，不影响其他页面）。

```javascript
// ========== 时间轴渲染器 ==========

class TimelineRenderer {
    constructor() {
        this.container = document.getElementById('timelineContainer');
        this.data = typeof timelineData !== 'undefined' ? timelineData : [];
        this.currentLevel = 1;  // 1=全景, 2=中距, 3=细节
        this.expandedTopics = new Set();  // 记录展开的主题
        this.expandedEntries = new Set();  // 记录展开的条目
        this.zoomSlider = null;
        this.zoomIndicator = null;
    }

    /**
     * 主渲染方法
     */
    render() {
        if (!this.container) return;
        this.renderControls();
        this.renderTimeline();
        this.initScrollAnimations();
        this.bindWheelZoom();
        // 初始化缩放指示器的 active 状态
        document.querySelectorAll('.zoom-level').forEach(el => {
            el.classList.toggle('active', parseInt(el.dataset.level, 10) === this.currentLevel);
        });
    }

    /**
     * 渲染缩放控制组件
     */
    renderControls() {
        const controlsHtml = `
            <div class="timeline-controls">
                <div class="zoom-control">
                    <span class="zoom-label">缩放</span>
                    <input type="range" class="zoom-slider" id="zoomSlider" 
                           min="1" max="3" value="${this.currentLevel}" step="1">
                    <div class="zoom-indicator">
                        <span class="zoom-level" data-level="1">全景</span>
                        <span class="zoom-level" data-level="2">中距</span>
                        <span class="zoom-level" data-level="3">细节</span>
                    </div>
                </div>
                <div class="timeline-stats">
                    <span class="stat-item">${this.data.length} 个主题</span>
                    <span class="stat-divider">·</span>
                    <span class="stat-item">${this.getTotalDays()} 天学习</span>
                    <span class="stat-divider">·</span>
                    <span class="stat-item insight-count">${this.getInsightCount()} 💡</span>
                </div>
            </div>
        `;

        // 插入到 container 前面
        const existingControls = this.container.parentElement.querySelector('.timeline-controls-wrapper');
        if (existingControls) {
            existingControls.innerHTML = controlsHtml;
        } else {
            const wrapper = document.createElement('div');
            wrapper.className = 'timeline-controls-wrapper';
            wrapper.innerHTML = controlsHtml;
            this.container.parentElement.insertBefore(wrapper, this.container);
        }

        this.bindControls();
    }

    /**
     * 绑定控制事件
     */
    bindControls() {
        const slider = document.getElementById('zoomSlider');
        if (slider) {
            slider.addEventListener('input', (e) => {
                this.setZoomLevel(parseInt(e.target.value, 10));
            });
        }

        const indicator = document.querySelector('.zoom-indicator');
        if (indicator) {
            indicator.addEventListener('click', (e) => {
                const level = e.target.dataset.level;
                if (level) {
                    this.setZoomLevel(parseInt(level, 10));
                    const slider = document.getElementById('zoomSlider');
                    if (slider) slider.value = level;
                }
            });
        }
    }

    /**
     * 设置缩放级别
     */
    setZoomLevel(level) {
        if (this.currentLevel === level) return;
        this.currentLevel = level;

        // 更新指示器
        document.querySelectorAll('.zoom-level').forEach(el => {
            el.classList.toggle('active', parseInt(el.dataset.level, 10) === level);
        });

        // 重新渲染
        this.container.dataset.level = level;
        this.renderTimeline();
    }

    /**
     * 渲染时间轴主体
     */
    renderTimeline() {
        if (!this.container || this.data.length === 0) {
            this.container.innerHTML = '<div class="timeline-empty">暂无学习记录</div>';
            return;
        }

        let html = '<div class="timeline">';

        this.data.forEach((topic, index) => {
            html += this.renderTopic(topic, index);
        });

        html += '</div>';
        this.container.innerHTML = html;

        // 绑定展开事件
        this.bindExpandEvents();
    }

    /**
     * 渲染单个主题
     */
    renderTopic(topic, index) {
        const isOngoing = !topic.end;
        const duration = this.calculateDuration(topic);
        const tagsHtml = topic.tags.map(t => `<span class="topic-tag">#${t}</span>`).join('');

        let html = `
            <div class="timeline-item topic-item ${isOngoing ? 'ongoing' : ''}" data-topic-id="${topic.id}">
                <div class="timeline-marker ${isOngoing ? 'pulse' : ''}"></div>
                <div class="timeline-line"></div>
                <div class="topic-content">
                    <div class="topic-header">
                        <h3 class="topic-title">${this.escapeHtml(topic.title)}</h3>
                        <div class="topic-meta">
                            <span class="topic-duration">${duration}天</span>
                            <span class="topic-range">${topic.start} ~ ${topic.end || '进行中'}</span>
                        </div>
                    </div>
                    <div class="topic-tags">${tagsHtml}</div>
        `;

        // Level 1: 只显示主题信息
        if (this.currentLevel === 1) {
            html += `<div class="topic-summary">${topic.entries.length} 条记录</div>`;
        }
        // Level 2: 显示周分组
        else if (this.currentLevel === 2) {
            html += this.renderWeekGroups(topic);
        }
        // Level 3: 显示每日详情
        else {
            html += this.renderDayEntries(topic);
        }

        html += '</div></div>';
        return html;
    }

    /**
     * 渲染周分组（Level 2）
     */
    renderWeekGroups(topic) {
        const weeks = this.groupByWeek(topic);
        let html = '<div class="week-groups">';

        weeks.forEach((week, weekIndex) => {
            const hasInsight = week.entries.some(e => e.isInsight);
            html += `
                <div class="week-group ${hasInsight ? 'has-insight' : ''}" data-week="${week.key}">
                    <div class="week-marker ${hasInsight ? 'insight-marker' : ''}">
                        ${hasInsight ? '💡' : ''}
                        <span class="week-label">${week.label}</span>
                    </div>
                    <div class="week-entries">
                        ${week.entries.map(e => `
                            <div class="entry-preview ${e.isInsight ? 'insight' : ''}" 
                                 data-date="${e.date}" data-topic="${topic.id}">
                                <span class="entry-date">${e.date}</span>
                                <span class="entry-summary">${this.escapeHtml(this.getSummary(e.content))}</span>
                            </div>
                        `).join('')}
                    </div>
                </div>
            `;
        });

        html += '</div>';
        return html;
    }

    /**
     * 渲染每日条目（Level 3）
     */
    renderDayEntries(topic) {
        const allDates = this.getDateRange(topic);
        // 用 Map 加速查找，避免每条都 Array.find
        const entryMap = new Map(topic.entries.map(e => [e.date, e]));
        let html = '<div class="day-entries">';

        allDates.forEach(date => {
            const entry = entryMap.get(date);
            const hasRecord = !!entry;

            if (hasRecord) {
                const isExpanded = this.expandedEntries.has(`${topic.id}-${date}`);
                html += `
                    <div class="day-entry ${entry.isInsight ? 'insight' : ''} ${isExpanded ? 'expanded' : ''}"
                         data-date="${date}" data-topic="${topic.id}">
                        <div class="day-marker ${entry.isInsight ? 'insight-marker' : ''}">${entry.isInsight ? '💡' : ''}</div>
                        <div class="day-line"></div>
                        <div class="day-content">
                            <div class="day-header clickable" data-action="toggle">
                                <span class="day-date">${date}</span>
                                <span class="day-summary">${this.escapeHtml(this.getSummary(entry.content))}</span>
                                <svg class="expand-icon" viewBox="0 0 24 24" width="16" height="16">
                                    <path d="M6 9l6 6 6-6" fill="none" stroke="currentColor" stroke-width="2"/>
                                </svg>
                            </div>
                            <div class="day-full" style="max-height: ${isExpanded ? 'none' : '0'}; opacity: ${isExpanded ? '1' : '0'}">
                                <div class="day-full-content">
                                    ${this.formatContent(entry.content)}
                                </div>
                            </div>
                        </div>
                    </div>
                `;
            } else {
                // 无记录的日子
                html += `
                    <div class="day-entry empty">
                        <div class="day-marker empty-marker"></div>
                        <div class="day-line empty-line"></div>
                        <div class="day-content">
                            <span class="day-date muted">${date}</span>
                        </div>
                    </div>
                `;
            }
        });

        html += '</div>';
        return html;
    }

    /**
     * 按周分组
     */
    groupByWeek(topic) {
        const weeks = new Map();

        topic.entries.forEach(entry => {
            const date = new Date(entry.date);
            const year = date.getFullYear();
            const weekNum = this.getWeekNumber(date);
            const key = `${year}-W${weekNum}`;
            const label = `${year}年第${weekNum}周`;

            if (!weeks.has(key)) {
                weeks.set(key, { key, label, entries: [] });
            }
            weeks.get(key).entries.push(entry);
        });

        return Array.from(weeks.values()).sort((a, b) => a.key.localeCompare(b.key));
    }

    /**
     * 获取两个日期之间的所有日期
     */
    getDateRange(topic) {
        const start = new Date(topic.start);
        const end = topic.end ? new Date(topic.end) : new Date();
        const dates = [];

        const current = new Date(start);
        while (current <= end) {
            dates.push(current.toISOString().split('T')[0]);
            current.setDate(current.getDate() + 1);
        }

        return dates;
    }

    /**
     * 计算持续天数
     */
    calculateDuration(topic) {
        const start = new Date(topic.start);
        const end = topic.end ? new Date(topic.end) : new Date();
        return Math.ceil((end - start) / (1000 * 60 * 60 * 24)) + 1;
    }

    /**
     * 获取内容摘要（取前50字符）
     */
    getSummary(content) {
        const clean = content.replace(/💡/g, '').trim();
        return clean.length > 50 ? clean.slice(0, 50) + '...' : clean;
    }

    /**
     * 格式化内容（处理 Markdown）
     */
    formatContent(content) {
        // 替换 💡 标记为带样式的 span
        let formatted = content.replace(/💡\s*/g, '<span class="insight-inline">💡 </span>');
        // 列表处理：连续的 - 开头行包裹为 <ul><li>...</li></ul>
        // 需要处理多组列表（中间有空行分隔的情况）
        formatted = formatted.replace(/(^- .+\n?)+/gm, (match) => {
            const items = match.trim().replace(/^- (.+)$/gm, '<li>$1</li>');
            return `<ul>${items}</ul>`;
        });
        // 段落处理：空行分隔的文本块包裹为 <p>，但跳过已有的 HTML 块级标签
        formatted = formatted.split('\n\n').map(block => {
            const trimmed = block.trim();
            if (trimmed.startsWith('<ul>') || trimmed.startsWith('<p>')) return trimmed;
            return `<p>${trimmed}</p>`;
        }).join('');
        return formatted;
    }

    /**
     * 获取总天数
     */
    getTotalDays() {
        const allDates = new Set();
        this.data.forEach(topic => {
            this.getDateRange(topic).forEach(d => allDates.add(d));
        });
        return allDates.size;
    }

    /**
     * 获取灵感总数
     */
    getInsightCount() {
        return this.data.reduce((count, topic) => {
            return count + topic.entries.filter(e => e.isInsight).length;
        }, 0);
    }

    /**
     * 获取 ISO 周数
     */
    getWeekNumber(date) {
        const d = new Date(Date.UTC(date.getFullYear(), date.getMonth(), date.getDate()));
        const dayNum = d.getUTCDay() || 7;
        d.setUTCDate(d.getUTCDate() + 4 - dayNum);
        const yearStart = new Date(Date.UTC(d.getUTCFullYear(), 0, 1));
        return Math.ceil((((d - yearStart) / 86400000) + 1) / 7);
    }

    /**
     * 绑定展开/折叠事件
     */
    bindExpandEvents() {
        document.querySelectorAll('.day-header[data-action="toggle"]').forEach(header => {
            header.addEventListener('click', () => {
                const entry = header.closest('.day-entry');
                const date = entry.dataset.date;
                const topic = entry.dataset.topic;
                const key = `${topic}-${date}`;

                const full = entry.querySelector('.day-full');
                const isExpanded = entry.classList.toggle('expanded');

                if (full) {
                    if (isExpanded) {
                        // 动态计算内容高度，避免硬编码截断
                        full.style.maxHeight = full.scrollHeight + 'px';
                        full.style.opacity = '1';
                        this.expandedEntries.add(key);
                    } else {
                        full.style.maxHeight = '0';
                        full.style.opacity = '0';
                        this.expandedEntries.delete(key);  // 折叠时从 Set 中移除
                    }
                }
            });
        });
    }

    /**
     * 绑定鼠标滚轮缩放（Ctrl+滚轮）
     * 监听整个时间轴页面，而非仅控制区域
     */
    bindWheelZoom() {
        const page = document.getElementById('timelinePage');
        if (page) {
            page.addEventListener('wheel', (e) => {
                if (e.ctrlKey) {
                    e.preventDefault();
                    const delta = e.deltaY > 0 ? -1 : 1;
                    const newLevel = Math.max(1, Math.min(3, this.currentLevel + delta));
                    this.setZoomLevel(newLevel);
                    const slider = document.getElementById('zoomSlider');
                    if (slider) slider.value = newLevel;
                }
            }, { passive: false });
        }
    }

    /**
     * 初始化滚动入场动画
     */
    initScrollAnimations() {
        const observer = new IntersectionObserver((entries) => {
            entries.forEach(entry => {
                if (entry.isIntersecting) {
                    entry.target.classList.add('visible');
                    observer.unobserve(entry.target);
                }
            });
        }, { threshold: 0.1 });

        document.querySelectorAll('.timeline-item').forEach((item, index) => {
            item.style.animationDelay = `${index * 100}ms`;
            observer.observe(item);
        });
    }

    /**
     * HTML 转义
     */
    escapeHtml(text) {
        const d = document.createElement('div');
        d.textContent = text;
        return d.innerHTML;
    }
}
```
