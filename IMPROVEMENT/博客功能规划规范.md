Aletheia Blog 功能规划规范

## 一、基础架构

### 响应式布局

- **描述**：适配手机、平板、桌面端，支持各种屏幕尺寸
- **方案**：CSS Grid/Flexbox + 媒体查询，已通过 CSS 变量控制断点（768px/1024px/1440px）
- **优先级**：P0 核心
- **状态**：已有
- **预估**：已稳定

### 暗色/浅色切换

- **描述**：支持手动切换主题，自动记住用户偏好，支持系统主题跟随
- **方案**：CSS 变量 + prefers-color-scheme 媒体查询 + localStorage 持久化
- **优先级**：P0 核心
- **状态**：已有
- **预估**：已稳定

### SEO 优化

- **描述**：meta 标签优化、sitemap.xml、robots.txt、自动生成 og:title/og:description
- **方案**：静态 sitemap 生成脚本、统一的 meta 模板、JSON-LD 结构化数据
- **优先级**：P0 核心
- **状态**：部分已有（需完善 sitemap 自动化）
- **预估**：1-2 小时

### Open Graph 社交分享卡片

- **描述**：分享到微信、微博、Twitter 等平台时显示封面图、标题、描述
- **方案**：og:image、og:title、og:description、og:url 等 meta 标签，支持 Twitter Card
- **优先级**：P1 推荐
- **状态**：待开发
- **预估**：2-3 小时

### PWA 支持

- **描述**：可安装到手机桌面，支持离线访问，后台更新
- **方案**：Service Worker（Workbox）+ manifest.json + 离线缓存策略
- **优先级**：P1 推荐
- **状态**：待开发
- **预估**：4-6 小时

### 多语言 i18n

- **描述**：中英文切换，语言文件管理
- **方案**：JSON 语言文件 + i18n 切换逻辑，支持 URL 参数或路径区分
- **优先级**：P2 进阶
- **状态**：待开发
- **预估**：3-5 小时

### 加载动画

- **描述**：页面切换时的过渡动画，打字机效果展示
- **方案**：CSS 动画 + 打字机 JS 效果，当前已有基础打字机效果
- **优先级**：P1 推荐
- **状态**：已有
- **预估**：已稳定

### 自定义 404 页面

- **描述**：访问不存在的页面时显示友好的 404 页面
- **方案**：404.html 静态页面，可添加搜索框、随机文章链接
- **优先级**：P1 推荐
- **状态**：待开发
- **预估**：1-2 小时
