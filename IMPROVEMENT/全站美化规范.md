## 一、设计理念与风格定位

### 1.1 整体风格关键词

```
克制 · 质感 · 呼吸感 · 层次分明 · 统一性
```

- **克制**：不做过度装饰，每个视觉元素都有存在的理由
- **质感**：无论是暗色还是浅色，都要让用户感受到"精心打磨过"
- **呼吸感**：足够的留白，让内容成为主角
- **层次分明**：通过亮度/灰度/阴影建立清晰的信息层级
- **统一性**：全站使用统一的视觉语言，背景装饰、组件、动画协调一致

### 1.2 暗色主题气质定位

**关键词**：`深邃终端感` `加密美学` `冷静克制`

- 暗色不是"黑底绿字"的粗暴黑客风，而是带有温度的深邃
- 参考 Apple macOS Dark Mode 的层次体系（不是纯黑 #000000，而是 #0a0a0f）
- 强调色 #00ff88 作为视觉锚点，用于关键交互和品牌标识
- 强调色在暗色背景下要有发光感，但不要滥用（只用于真正重要的元素）

### 1.3 浅色主题气质定位

**关键词**：`温润纸面感` `学术清新` `沉稳有力`

- 浅色不是"白底黑字"的无聊办公风，而是有温度的纸张质感
- 参考高品质印刷品的用色，背景用 #fafafa（微暖白）而非纯白 #ffffff
- 强调色 #0a7d4f（深绿），与暗色的 #00ff88 属于同一色系，但更适合浅色背景
- 行内代码用 #d63384（玫红），与深绿形成优雅的学术感对比
- 整体感觉像是"精心排版的学术期刊网页版"

### 1.4 配色哲学

```
暗色：#0a0a0f（极深背景）+ #00ff88（荧光强调）
浅色：#fafafa（微暖白背景）+ #0a7d4f（沉稳深绿）

核心原则：强调色是"灯塔"，不是"装饰"
```
