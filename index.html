🕐 时间轴使用指南

🗺️ 平移与缩放

  • 右键拖拽 / 触控板双指滑动 平移画布
  • ⌘+滚轮 / Ctrl+滚轮 以鼠标为中心缩放
  • 双指捏合 移动端缩放
  • 方向键 平移 · +- 缩放 · 0 重置

📇 节点与卡片

  • 悬浮 节点快速预览卡片
  • 点击 节点锁定展开 / 折叠卡片
  • 展开全部 / 折叠全部 批量操作
  • 同一天多条记录自动合并为一个节点

🎯 主题筛选

  • 点击 上方彩色主题条 筛选该主题节点
  • 可同时选中多个主题（OR 逻辑）
  • 点击空白处 取消所有筛选

🔍 检索与定位

  • 年 / 月 / 日下拉筛选 + 跳转按钮
  • 右下角 ⊕ 定位到今天或最近记录

🎨 其他

  • ◐ 切换深色 / 浅色主题
  • 缩放滑块 25% – 200%
  • 年/月视图下时间轴出现年份/月份标记
