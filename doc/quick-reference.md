# Markdown 速查卡

> 写文章时看一眼就够了，不需要记。

---

## 基础（必会）

```
**粗体**  *斜体*  ~~删除~~  `代码`
[链接](url)  ![图片](url)
# 标题  ## 二级  ### 三级
- 列表  1. 有序  - [ ] 待办  - [x] 完成
> 引用
```

## 高级（按需用）

```
==高亮==        → 黄色标记
H~2~O           → 下标
E=mc^2^         → 上标
:smile:         → 😄
$E=mc^2$        → 行内公式
$$公式$$        → 块级公式
===标题===      → 等效 ##
```

## 扩展块（记3个最常用的就行）

### 1. 脚注 — 鼠标悬停就能看

```
海德格尔提出此在的概念[^1]。

[^1]: 脚注内容写这里。
```

### 2. 提示框 — 5种颜色

```
> [!NOTE]      蓝色  辅助说明
> [!TIP]       绿色  技巧建议
> [!IMPORTANT] 紫色  关键信息
> [!WARNING]   橙色  注意事项
> [!CAUTION]   红色  危险警告
```

### 3. HTML 小工具（需要时复制）

```
<details><summary>点击展开</summary>隐藏内容</details>
<kbd>Ctrl</kbd> + <kbd>C</kbd>
<u>下划线</u>  <ins>荧光笔高亮</ins>  <small>小字</small>
<center>居中</center>
<mark style="background:#ff6b6b">自定义颜色标记</mark>
```
