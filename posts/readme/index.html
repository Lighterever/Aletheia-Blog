一些从深处取出的东西

这个网站起源于一个密钥室——把文字加密，输入密钥才能看到。那时候我觉得有些东西只该给愿意看的人看。

后来我发现，藏起来不如让人看见，就让文章筛选出是谁愿意看吧。

所以这个网站现在是对外的。我希望你能看到我在做什么、怎么想的、踩过什么坑、走过什么路。

这里会有：

  • 我学数学和计算机时挖到的底层结构——比如贪心算法为什么是对的，不只是怎么用
  • 技术项目的完整记录——从为什么开始，到卡在哪里，到怎么解决
  • 一些深夜想出来的东西——关于理想、意义、应试，那些时常浮现的念头
  • 偶然发现的联系——离散数学和数据结构是一回事，密码学和数论是一回事，哲学和形式系统也是一回事
  • So on…

我不确定这些有没有用。但我感觉，学东西的时候最缺的不是教程，是一个人真实的学习过程——卡住的地方、想通的瞬间、走弯路之后回头看才明白的路线。如果这些记录能帮到同样在走的人，那就更好了。

如果你在这里看到了有意思的东西，欢迎来聊。讨论、反驳、补充，都好。一个人的穷究有尽头，两个人的对话没有。（人类的智慧结晶往往是共同努力的结果）

密钥就在最显眼的地方。

联系方式：me@lighterever.com

密钥室

密钥为 aletheia。输入后解锁文章检索页面，解锁状态保存在 sessionStorage 中，关闭标签页后需重新输入。

文章检索

  • 搜索框支持标题、标签、正文匹配（暂为不稳定功能）
  • 标签栏多选筛选，支持 OR / AND 逻辑切换
  • 列头 DATE / TITLE / TAGS 可点击排序，显示 ↑↓ 箭头

时间轴

/timeline 页面以横向画布展示学习轨迹。支持：

  • 平移：左键按住拖拽 / 触控板双指滑动
  • 缩放：⌘+滚轮 (Mac) / Ctrl+滚轮 (Win)
  • 节点：悬浮鼠标预览卡片、点击锁定展开/折叠
  • 主题筛选：点击上方彩色主题条筛选相关节点（可多选）
  • 日期跳转：年/月/日下拉 + 跳转按钮
  • 卡片关联：部分卡片可点击跳转到对应文章
